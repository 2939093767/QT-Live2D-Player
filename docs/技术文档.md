# Live2D Pet Settings 技术文档

## 一、产品简介

**Live2D Pet Settings** 是一款基于 Qt 框架开发的 Windows 桌面虚拟宠物应用，融合了 Live2D 实时渲染、计算机视觉面部捕捉、本地 AI 对话等多项前沿技术。用户可以通过摄像头实时捕捉面部动作，驱动 Live2D 虚拟形象做出自然的表情和动作，同时支持与本地 AI 助手进行对话交互。

应用采用透明窗口 + 桌面置顶的呈现方式，虚拟宠物可以悬浮在桌面任意位置，不影响用户正常使用电脑，为用户提供陪伴式的交互体验。

---

## 二、核心功能概括

| 功能模块 | 核心能力 |
|---------|---------|
| **Live2D 模型渲染** | 支持 Live2D Cubism 模型的加载与实时渲染，支持动作、表情、物理效果 |
| **面部动作捕捉** | 基于 dlib + OpenCV 的实时人脸检测与 68 点关键点识别，支持头部、眼部、嘴部追踪 |
| **桌面宠物模式** | 透明无边框窗口、鼠标穿透、桌面置顶、拖拽移动 |
| **AI 对话助手** | 基于 LLaMA.cpp 的本地大模型推理，支持多轮对话与技能扩展 |
| **AI 技能系统** | 可扩展的技能插件机制，通过 Markdown 定义技能行为 |
| **系统资源监控** | 实时监控 CPU、内存、显存使用率，可视化展示系统状态 |
| **多主题多语言** | 支持深浅主题切换，中英文界面切换 |
| **配置持久化** | 所有用户设置自动保存，下次启动自动恢复 |

## 五、模块功能说明

### 5.1 Live2D 渲染模块

#### 功能说明
负责 Live2D 模型的加载、渲染、动画播放与交互响应。

#### 核心能力
- **模型加载**：支持标准 Live2D Cubism 4.x 模型格式，自动解析模型配置、纹理、动作、表情
- **实时渲染**：基于 OpenGL 的硬件加速渲染，保证流畅的动画效果
- **动作系统**：支持动作组管理、动作队列、动作打断与过渡
- **表情系统**：支持表情切换、表情叠加、参数化表情控制
- **物理模拟**：头发、衣物等物理效果实时计算
- **交互响应**：支持鼠标点击、拖拽等交互触发对应动作

#### 性能优化
- 采用 GPU 硬件加速渲染，降低 CPU 占用
- 模型纹理预加载，避免运行时卡顿
- 离屏渲染优化，减少不必要的重绘
- 动画帧间插值，提升流畅度

#### 突出技术
- 基于 Live2D Cubism Framework 的二次封装，模块化设计
- 与 Qt 信号槽机制深度整合，事件驱动的动画调度
- 支持多模型切换与动态加载

---

### 5.2 面部捕捉模块

#### 功能说明
通过摄像头实时捕捉用户面部动作，驱动 Live2D 模型做出相应表情和头部运动。

#### 核心能力
- **人脸检测**：实时检测画面中的人脸位置
- **关键点识别**：精准识别 68 个面部特征点
- **头部姿态估计**：计算头部的偏航、俯仰、翻滚三个旋转角
- **眼部追踪**：检测眼球运动方向，驱动模型视线
- **嘴部追踪**：识别嘴部开合程度，驱动模型口型
- **眨眼检测**：检测眨眼动作，同步到模型
- **表情识别**：将面部表情映射为模型表情
- **参数调节**：灵敏度、平滑度可调节，适配不同用户

#### 性能优化
- 独立检测线程，不阻塞 UI 主线程
- 多级降采样策略，平衡精度与性能
- 检测结果帧间平滑，消除抖动
- 自适应检测帧率，根据性能动态调整

#### 突出技术
- dlib + OpenCV 混合方案，兼顾精度与速度
- 基于几何特征的姿态解算算法
- 多线程流水线：采集 → 检测 → 计算 → 渲染
- 失败检测自动恢复机制

---

### 5.3 AI 对话模块

#### 功能说明
集成本地大语言模型，提供智能对话与技能扩展能力。

#### 核心能力
- **本地推理**：完全本地化运行，保护用户隐私
- **多轮对话**：支持上下文记忆的多轮对话
- **流式输出**：逐字生成回复，提升交互体验
- **情绪识别**：根据对话内容识别情绪，驱动模型表情
- **技能系统**：可扩展的技能插件机制
- **模型切换**：支持加载不同的 LLM 模型

#### 性能优化
- 模型量化（4-bit / 8-bit），降低显存占用
- CPU + GPU 混合推理，充分利用硬件资源
- 对话上下文缓存，避免重复计算
- 异步推理，不阻塞界面响应

#### 突出技术
- 基于 LLaMA.cpp 的轻量级本地推理方案
- Markdown 驱动的技能定义系统
- 情绪 → 表情映射的交互闭环
- 完全离线运行，无需联网

### 5.4 系统监控模块

#### 功能说明
实时监控系统资源使用情况，在界面上可视化展示。

#### 核心能力
- **CPU 监控**：实时 CPU 使用率统计
- **内存监控**：物理内存使用量与使用率
- **显存监控**：GPU 显存使用情况（通过 DXGI）
- **实时刷新**：秒级数据更新
- **可视化展示**：进度条 + 数值双重展示

#### 性能优化
- 低开销的数据采集，对系统性能影响极小
- 独立监控线程，与主线程解耦
- 采样频率自适应，避免资源浪费

#### 突出技术
- Windows Native API 深度集成
- DXGI 接口获取 GPU 信息，兼容性强
- 高精度时间戳计算，数据准确可靠

### 5.5 配置管理模块

#### 功能说明

#### 性能优化

- 批量写入优化，避免频繁写盘
- 异步落盘，不阻塞主线程

#### 突出技术
- 基于观察者模式的配置变更通知
- 类型安全的配置访问接口
- 配置版本管理，支持平滑升级

#### 功能说明
提供项目专用的自定义 UI 控件，提升界面交互体验。

### 6.3 构建说明

1. **环境准备**
   - 安装 Qt 6.7.3，确保包含 MSVC2019 64bit 组件
   - 安装 Visual Studio 2019 Build Tools
   - 配置系统环境变量

2. **依赖库放置**
   - 将第三方库文件放入 `libfiles/` 目录
   - 将头文件放入 `inc/` 目录
   - 将 DLL 文件放入 `dllfile/` 目录

3. **编译步骤**
   - 使用 Qt Creator 打开 `Live2DpetSettings.pro`
   - 选择正确的 Qt Kit
   - 点击构建按钮进行编译
   - 编译产物位于构建目录下

4. **运行部署**
   - 将 `dllfile/` 中的 DLL 复制到可执行文件目录
   - 将模型资源、配置文件放到对应目录
   - 使用 `windeployqt` 工具部署 Qt 依赖
